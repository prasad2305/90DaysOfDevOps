
# Basic File Read and Write Operations

* `touch notes.txt` : Creates an empty file named notes.txt

* `echo "I am a DevOps Engineer." > notes.txt` : Writes text to the file

* `echo "echo "I work with Linux, Docker, and Kubernetes." >> notes.txt` : Append the second line : Adds text to the end of the file

* `echo "I automate deployments using CI/CD pipelines." | tee -a notes.txt` : Appends text to the file and displays it on the terminal.

* `cat notes.txt` : Display the entire file

* `cat notes.txt | head -n 1` : View the first 2 lines (Displays the first 2 lines of the file.)

* `cat notes.txt | tail -n 2` : View the last 2 lines (Displays the last 2 lines of the file.)
